# AGENTS.md

## Project

officelens (`ooxml-a11y`) is an offline accessibility auditor for DOCX and PPTX. It reads the OOXML package directly and flags missing alt text, heading order, language, table headers, and link text across the main part, headers, footers, and notes. It also ships a typed library and a fully client-side browser playground. Files are read locally; there are no network calls, no telemetry, no JVM, and no GUI. Output is text, stable JSON, or SARIF 2.1.0.

## Commands

- `bun install` — install dependencies.
- `bun test` — run the test suite in `tests/`.
- `bun run typecheck` — `tsc --noEmit`.
- `bun run make-fixtures` — regenerate the fixtures under `fixtures/`.
- `bun run build:site` — bundle `src/index.ts` into `site/assets/demo.js` (esbuild, IIFE).
- `bun run check:site` — validate every `site/*.html`.

## Layout

- `src/` — implementation and the CLI entry point in `src/cli.ts`.
- `tests/` — `bun test` files.
- `site/` — static pages and `site/assets/` (styles, self-hosted fonts, the generated playground bundle).
- `scripts/` — `build-site.mjs`, `check-site.mjs`, and `make-fixtures.ts`.

## Conventions and hard rules

- The site is fully static and offline: no external scripts or stylesheets, no network `src`, no telemetry.
- `site/assets/lens.css` is a shared design system copied byte-identical across the Lenses suite. Do not diverge it; per-tool changes go in `site/assets/theme.css`.
- `site/assets/demo.js` is generated by `scripts/build-site.mjs`. Edit `src/`, then rebuild; never hand-edit the bundle.
- `site/assets/fonts/*.woff2` are self-hosted Geist (SIL Open Font License 1.1). Do not swap them for a CDN.
- Every `site/*.html` must pass `bun run check:site`: exactly one `<h1>` and one `<main>`, a skip link whose `#fragment` matches an element id, and only classes defined in `lens.css` or `theme.css`.
- The CLI contract is stable: `--json` output and exit codes `0` (clean), `1` (findings at or above `--fail-on`), `2` (invalid usage or an unparseable OOXML package), `3` (I/O error).
